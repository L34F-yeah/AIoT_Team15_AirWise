# AirWise 研究論述：證據、預期貢獻與摘要

Nov 11, 2026 · @AidsLab

## 1. A–F 研究故事與證據

AirWise 的核心論述：台灣運動人口創新高，空污會削減運動效益，而民眾手上只有即時數字；LLM 可以按需說明，但在健康問題上幻覺率高達 50–82%，必須用架構而非提示詞來管住它。

### A. Attention Getter：戶外運動者的即時空污風險與排程痛點

- **運動人口創新高**：運動部 2025 年運動現況調查（n = 25,472）顯示，規律運動人口 35.6%，為 2014 年以來最高；運動參與率 83.3% [4]。
- **空污會「打折」運動效益**：中興大學與 UCL 合作、追蹤 150 萬名成人的 *BMC Medicine*（2025）研究發現，每週運動 2.5 小時以上可降低約 30% 死亡風險；但 PM2.5 年均超過 25 μg/m³ 時，效益降到 12–15% [2]。該研究由台中的中興大學主導，與本專題實驗區域相同。
- **短時暴露也看得到影響**：*Sports Medicine* 分析美國 9 場馬拉松、逾 250 萬筆完賽成績，PM2.5 每增加 1 μg/m³，男性完賽慢 32 秒、女性慢 25 秒（相關性研究）[3]。
- **在地案例**：2026 年春節前，境外污染加上弱風，中南部 PM2.5 時均值達 35–45 μg/m³，環境部預告除夕與初一全台橙燈，並建議民眾「出門前查看環境即時通」[5]。官方建議仍是叫人自己看數字。

### B. But：被動數據、缺少推理、LLM 會幻覺與越權

- **平均變好，個人風險仍在**：2025 年全國 PM2.5 年均 12.8 μg/m³，較 2019 年降約 21% [6]；但弱風時數增加、氣溫上升讓臭氧更難改善 [7]。
- **現有系統是被動的**：監測網與 App 呈現即時與歷史數值；官方預報自述受天氣影響而有不確定性 [5]，且不會把數值轉成「這個人、這個時段、這個強度」的建議。
- **非官方資料不可盡信**：環境部回應 IQAir 2025 報告時指出，低成本感測器受環境與設備影響，讀數可能與標準測站不同 [6]。
- **LLM 健康幻覺率高**：*Communications Medicine*（2025）以 300 個臨床情境測試 6 個 LLM，幻覺率 50–82%；加上防幻覺提示詞後平均仍有 44% [8]。
- **引用不可靠**：*BMJ Open* 測試 5 個主流聊天機器人，50% 健康回答有問題，參考文獻完整度平均僅 40% [9]。

### C. Cure：規則錨定、工具導向的 AI Agent

本專題提出 **AirWise**，一個結合環境部官方資料、短期時間序列預測與官方 AQI 活動建議的工具導向 AI Agent。LLM 只負責理解問題與解釋結果；等級與建議由可驗證的模型與規則產生。

### D. Development：方法

- **資料工具**：環境部 AQI API（aqx_p_432）、中央氣象署鄉鎮預報（F-D0047-075）。
- **白名單 Function Calling**：OpenAI function calling 只能呼叫預先定義的工具（取資料、預測、查規則、檢索文件），不得自行產生數值。
- **時間序列預測**：持續法為基線，XGBoost、LSTM 為主模型；以 split conformal prediction 產生信賴區間。
- **官方規則庫**：AQI 六級 × 族群 × 活動強度的 YAML 規則表，搭配 RAG 提供原文引用。
- **安全降級**：資料中斷時換測站重試，仍失敗則回覆官方連結；引用檢查失敗改用模板回答；詢問用藥、診斷等超出範圍的問題時拒答並建議就醫。

### E. Experiments：評估規劃

- **E1 滾動回測**：臺中測站 2023–2025 年逐時觀測資料（可延伸至 2026 年），以滾動原點（rolling-origin）方式回測 1/6/12/24 小時預測。
- **E2 Agent 情境測試**：50 題在地情境，其中至少 10 題為異常或越界情境（資料中斷、缺資訊、要求用藥或診斷），比較純 LLM、LLM + 即時資料與 AirWise。
- **E3 線上問卷**：AirWise 與環境即時通的截圖比較，目標 20 份以上。

### F. Findings：預期成果（預先設定的目標，非實驗結果）

依規範「提案階段不得虛構實驗結果」，以下為事前訂定、待驗證的目標：

| 指標 | 預期目標 |
| --- | --- |
| E1 預測誤差 | 6–24 小時時距的 MAE 與 RMSE 相對持續法改善 10% 以上 |
| E1 區間覆蓋率 | α = 0.1 時，實測覆蓋率接近 90% |
| E2 來源揭露率 | 100%：每個建議都附測站、資料時間與規則 ID |
| E2 安全降級率 | 100%：異常與越界情境皆正確拒答、反問或回退 |
| E2 一致率與幻覺率 | 指引一致率高於、幻覺率低於兩個 LLM 基線 |

## 2. 三個說服力面向

口試或簡報開場可以用這三句話回答「為什麼值得做」，每句都有獨立來源支撐。

| 面向 | 一句話 | 支撐證據 |
| --- | --- | --- |
| **Important 重要** | 空污仍是重大健康風險，而且會削減運動帶來的健康效益 | 2023 年全球 790 萬人死亡與空污相關 [1]；PM2.5 年均超過 25 μg/m³ 時運動降低死亡風險的效果從約 30% 降到 12–15% [2]；台灣規律運動人口 35.6% 創新高 [4] |
| **Interesting 有趣** | 「要不要去跑步」不是是非題，而是時段、強度與族群的權衡 | 馬拉松完賽時間隨 PM2.5 增加而變慢 [3]；2026 春節前境外污染讓中南部時均值達 35–45 μg/m³ [5]；主導運動與空污研究的團隊就在台中 [2] |
| **Innovation 創新** | 用架構而非提示詞管住 LLM，並把預測不確定性轉成有理論上界的保守決策 | 防幻覺提示詞只能把幻覺率從 66% 降到 44% [8]；領域 Agent 趨勢是工具呼叫、RAG 與可稽核證據鏈 [10][11]；尚未見到結合個人敏感度與官方規則的空品健康 Agent |

**可以一併提的政策趨勢**：環境部自 2026 年起在台北、台中、台南啟動 PM0.1 超細懸浮微粒監測 [12]，並訂下 2030 年 PM2.5 年均低於 10、2035 年低於 8 μg/m³ 的目標 [6]。標準與指標持續變動，正好說明規則庫要可維護、可更新。

## 4. 學術價值

**(1) 為「用架構管住 LLM」提供健康領域的實證。** 既有研究顯示提示詞只能減少約一半幻覺 [8]。AirWise 改由架構限制 LLM 的權限，並以消融實驗量化每個模組的貢獻，能回答「哪一層防護最有效」。

**(2) 把預測不確定性接到健康決策。** 空品預測研究多停在誤差指標 [13][14]。本專題把信賴區間直接用於等級決策，並給出可檢驗的機率上界；若實測覆蓋率偏離理論值，也能具體量化空品時間序列違反可交換假設的程度。

**(3) 把暴露科學轉譯為個人行為建議。** 流行病學證據顯示運動效益與空污風險需要權衡 [2]。AirWise 以「換時段、降強度、改室內」取代一律禁止，是將權衡思維寫成可執行規則的一個實例。

**(4) 建立可重複的 Agent 評測方法。** 領域 Agent 多以專家主觀評分為主 [10]。本專題以官方指引作為標準答案，定義一致率、幻覺率、來源揭露率與安全降級率，其他領域的規則型 Agent 可以沿用。

**(5) 在地化且可重現。** 全部使用政府公開資料與官方指引，可作為台灣空品健康 AI 研究的基線，也能在 PM0.1 等新指標上線後擴充規則庫 [12]。

## 5. 專業摘要

臺灣規律運動人口於 2025 年達 35.6%，創 2014 年以來新高；然而大型世代研究顯示，當 PM2.5 年均濃度超過 25 μg/m³ 時，規律運動降低死亡風險的效益將由約 30% 降至 12–15%。民眾安排晨跑或戶外活動時，現有空品系統僅被動呈現即時與歷史監測值，缺乏可靠的短期趨勢推估，也無法將數據轉化為符合個人敏感度與活動強度的具體建議；若直接詢問大型語言模型（LLM），臨床情境研究顯示其幻覺率高達 50–82%，即使加入防幻覺提示仍有約 44%。

為此，本專題提出 AirWise，一個規則錨定、工具導向的空氣品質健康顧問 AI Agent。系統以 OpenAI 白名單 Function Calling 串接環境部 AQI 與中央氣象署預報資料，以 XGBoost 與 LSTM 進行 1 至 24 小時 AQI 預測，並以 split conformal prediction 估計信賴區間。決策階段依環境部 AQI 活動建議建構「等級 × 族群 × 活動強度」規則庫，對敏感族群採預測上界之預防原則，理論上可將低估警示機率控制在 α 以內。LLM 僅負責解析問題與解釋結果，回答須附測站、資料時間與規則來源；引用檢查失敗，或遇資料中斷、用藥與診斷等越界請求時，系統即安全降級。

評估規劃以臺中測站 2023–2025 年逐時資料進行滾動回測，並以 50 題含異常與越界情境的在地問答集，比較純 LLM 與資料增強 LLM 兩種基線，輔以線上問卷。預期 AirWise 在 6–24 小時預測之 MAE 與 RMSE 較持續法改善 10% 以上，來源揭露率與安全降級率達 100%，並在指引一致率與幻覺率上優於基線；上述皆為待驗證之預期目標。本專題的貢獻在於以系統架構而非提示詞約束 LLM，並將預測不確定性轉化為可驗證、可追溯的個人化健康行為建議。
